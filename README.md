# GameBoost Pro v2

A Kotlin + Jetpack Compose Android starter project.

## Build
1. Open the folder in Android Studio.
2. Let Gradle sync.
3. Build > Build APK(s).

## Honest limitations
- The overlay counter is a demo/tick counter, not universal game-render FPS.
- GPU usage/temperature is not available on every Android phone.
- Android apps cannot reliably force-clean all other apps' RAM.
- Universal live voice changer injection into every game is not supported by public Android APIs.
