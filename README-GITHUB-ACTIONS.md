# APK বানানোর সহজ নিয়ম

1. এই project-এর সব ফাইল GitHub repository-তে upload করুন।
2. GitHub-এর **Actions** tab খুলুন।
3. **Build GameBoost Pro v2 APK** নির্বাচন করুন।
4. **Run workflow** চাপুন।
5. Build শেষ হলে নিচের **Artifacts** থেকে `GameBoost-Pro-v2-APK` download করুন।
6. ZIP extract করে `app-debug.apk` ফোনে install করুন।

নোট: এটি debug APK। ফোনে install করার সময় Unknown apps permission চাইতে পারে।
